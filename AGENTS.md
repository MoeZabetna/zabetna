# Notes for any agent (Claude or otherwise) working in this repo

- Read `README.md` first — layout, current build status, deployment.
- `apps/admin` is Next.js 16; it has its own `AGENTS.md` with framework-
  specific conventions (auto-generated by `next dev`, don't hand-edit the
  block between the `nextjs-agent-rules` markers).
- Before touching anything deploy-related for the Admin Panel — Vercel
  settings, `proxy.ts`/`middleware.ts`, routing that suddenly 404s — read
  [`docs/incidents/2026-08-30-admin-panel-outage.md`](docs/incidents/2026-08-30-admin-panel-outage.md).
  It documents three real, stacked root causes behind a ~12-hour outage,
  including a Vercel *project setting* (Framework Preset) that isn't
  visible anywhere in this repo's source and will cause the exact same
  symptom again if it ever gets unset.
- `docs/incidents/` is where postmortems like that one live going forward
  — add to it rather than only fixing-and-forgetting, the same way this
  one was written up.
